Permanently replaces the previously-planned Team Collaboration/Chat panel (reference/PROJECT_SPEC.md, reference/payroll_prototype.html — both frozen, unedited historical reference; not reflected here or anywhere in living documentation). There is no Chat tab, no message feed, no comment thread anywhere in this feature — the panel is single-purpose by design.

Master User screen shows the Create Task button, the Assignee filter, and the per-row action menu (Edit/Reassign, Cancel or Reopen depending on status, Delete). Assignee screen shows the same panel with no Create button and no Assignee filter — ownership-based visibility means an assignee only ever sees their own tasks in the first place (docs/architecture/authentication.md's "Tasks: ownership-based visibility" section), so there is nothing to filter by assignee. The one action an assignee has — Mark Complete — appears directly on the row, no menu needed. Sample data is illustrative, not seed data; the overdue/due-today badges are computed live from dueDate/status, never stored (docs/architecture/database/tasks.md §27a).
